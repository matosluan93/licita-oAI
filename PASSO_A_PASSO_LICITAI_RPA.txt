PASSO A PASSO ATUALIZADO - LICITAI
==================================

Atualizado em: 13/07/2026

Este guia foi feito para uso em maquina corporativa, inclusive quando o comando
"npm" nao funciona porque o Node.js nao esta instalado globalmente.


1. O QUE VOCE VAI USAR
----------------------

O LicitAI tem duas partes:

1. Aplicacao web
   Onde voce anexa o edital, analisa com IA e exporta o JSON para o RPA.

2. RPA LinkedIn
   Onde voce faz login no LinkedIn e roda a busca de profissionais.


2. CAMINHO DO PROJETO
---------------------

C:\Users\lfsantos17\OneDrive - Stefanini\Desktop\Aplicações\LicitAI


3. SE O NPM NAO FUNCIONA NA SUA MAQUINA
---------------------------------------

Se aparecer erro como:

nao tem problema.

Use os arquivos .bat que ficam nesta pasta:

C:\Users\lfsantos17\OneDrive - Stefanini\Desktop\Aplicações\LicitAI\scripts-windows

Esses arquivos tentam usar o Node interno do Codex, sem precisar instalar Node.js
globalmente no Windows.


4. ORDEM RECOMENDADA USANDO OS ARQUIVOS .BAT
--------------------------------------------

Abra esta pasta no Explorador de Arquivos:

C:\Users\lfsantos17\OneDrive - Stefanini\Desktop\Aplicações\LicitAI\scripts-windows

Depois de dois cliques nos arquivos abaixo, nesta ordem:

1. 00_VERIFICAR_NODE_CODEX.bat

   Serve para verificar se o Node interno do Codex esta disponivel.

   Se esse arquivo der erro dizendo que nao encontrou o Node interno, sera necessario
   pedir ao TI uma das opcoes abaixo:

   - liberar Node.js LTS oficialmente;
   - liberar Node.js portable para essa pasta do projeto;
   - permitir o uso do runtime local do Codex.


2. 01_INSTALAR_APLICACAO_WEB.bat

   Instala as dependencias da aplicacao web do LicitAI.

   Rode uma vez.
   Pode demorar alguns minutos.


3. 02_RODAR_APLICACAO_WEB.bat

   Inicia a aplicacao web.

   Quando abrir, acesse:

   http://localhost:4028/linkedin-sourcing

   IMPORTANTE:
   Nao feche essa janela enquanto estiver usando a tela do LicitAI.


4. 03_INSTALAR_RPA_LINKEDIN.bat

   Instala as dependencias do RPA e o navegador Chromium usado pelo Playwright.

   Rode uma vez.
   Pode demorar alguns minutos.


5. 04_LOGIN_LINKEDIN.bat

   Abre o navegador para voce fazer login manual no LinkedIn.

   Faca login normalmente.
   Aguarde o feed do LinkedIn carregar.

   A sessao fica salva em:

   C:\Users\lfsantos17\OneDrive - Stefanini\Desktop\Aplicações\LicitAI\rpa\linkedin-sourcer\.linkedin-session

   Nao compartilhe essa pasta com ninguem.


6. 05_RODAR_RPA_LINKEDIN.bat

   Roda a automacao.

   Esse arquivo vai pedir:

   - caminho do JSON exportado pela tela do LicitAI;
   - pasta onde deseja salvar a estrutura de documentos;
   - se deseja baixar curriculos automaticamente, nao baixar, ou confirmar um por um.


5. COMO GERAR O JSON NA TELA DO LICITAI
---------------------------------------

Na tela:

http://localhost:4028/linkedin-sourcing

Siga:

1. Anexe o edital em PDF ou cole o texto.
2. Informe o cliente da licitacao.
3. Selecione as empresas do grupo Stefanini.
4. Clique para analisar o edital.
5. Revise cargos, perfis e quantidades.
6. Exporte a configuracao para o RPA.

O arquivo exportado normalmente vai para a pasta Downloads.

Exemplo:

C:\Users\lfsantos17\Downloads\linkedin-campaign-123.json

Esse e o caminho que voce vai informar no arquivo:

05_RODAR_RPA_LINKEDIN.bat


6. PASTA DE DOCUMENTOS / ONEDRIVE
---------------------------------

Quando o script perguntar a pasta de documentos, voce pode informar a pasta
sincronizada do OneDrive/SharePoint.

Exemplo:

C:\Users\lfsantos17\OneDrive - Stefanini\Documents\Time Certificacoes\Pregoes

O RPA cria dentro dela a estrutura:

Pregoes 2026\Julho\<Cliente>\<Perfil>\<Profissional>

Dentro da pasta do profissional ficam:

- curriculo baixado, quando disponivel;
- perfil-linkedin.txt com dados e link do perfil.


7. RESULTADOS GERADOS PELO RPA
------------------------------

O RPA tambem gera arquivos nesta pasta:

C:\Users\lfsantos17\OneDrive - Stefanini\Desktop\Aplicações\LicitAI\rpa\linkedin-sourcer\output

Arquivos principais:

results-<campaignId>.json
licitacao-<campaignId>.xlsx
audit-log.ndjson
daily-usage.json

O Excel e o arquivo mais facil para visualizar:

licitacao-<campaignId>.xlsx

O JSON serve para importar de volta na tela:

results-<campaignId>.json


8. IMPORTAR RESULTADOS NA TELA
------------------------------

Volte para:

http://localhost:4028/linkedin-sourcing

Importe:

results-<campaignId>.json

A tela mostra os perfis encontrados e o ranking de aderencia.


9. CONTROLES DO RPA
-------------------

O RPA esta configurado com:

- busca somente dentro do LinkedIn;
- bloqueio de acesso fora de linkedin.com e licdn.com;
- limite de 30 perfis por execucao;
- limite diario de 100 perfis salvos;
- pausa maior a cada 8 perfis;
- parada automatica em captcha, checkpoint ou verificacao de seguranca;
- log de auditoria em output/audit-log.ndjson.


10. SE DER ERRO
---------------

Erro: "npm nao e reconhecido"

Use os arquivos .bat da pasta:

C:\Users\lfsantos17\OneDrive - Stefanini\Desktop\Aplicações\LicitAI\scripts-windows


Erro: "ERR_PNPM_IGNORED_BUILDS"

Esse erro pode aparecer durante a instalacao porque o pnpm interno bloqueia alguns
build scripts de dependencias.

Os scripts .bat atualizados contornam isso chamando o Node diretamente nos binarios
locais do projeto.

Se aparecer durante o arquivo 01_INSTALAR_APLICACAO_WEB.bat, veja se ele encontrou
a pasta node_modules depois. Se encontrou, rode:

02_RODAR_APLICACAO_WEB.bat

Se aparecer durante o arquivo 02_RODAR_APLICACAO_WEB.bat, atualize os scripts .bat
com a versao mais recente deste projeto.


Erro: "Node interno do Codex nao encontrado"

PeÃ§a ao TI para liberar Node.js LTS ou Node portable.


Erro: a tela nao abre

Verifique se o arquivo abaixo continua aberto:

02_RODAR_APLICACAO_WEB.bat

Se ele foi fechado, abra novamente.


Erro: LinkedIn pediu login

Rode novamente:

04_LOGIN_LINKEDIN.bat


Erro: LinkedIn pediu captcha/checkpoint

Pare a automacao.
Resolva manualmente no navegador.
Depois rode novamente.


Erro: arquivo JSON nao encontrado

Confira o caminho do JSON na pasta Downloads.
Use sempre o caminho completo.

Exemplo:

C:\Users\lfsantos17\Downloads\linkedin-campaign-123.json
